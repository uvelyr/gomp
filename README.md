
# GoMP3

TUI mp3 player written in Go and based on github.com/gdamore/tcell/v2


## Screenshots

![TUI Screenshot](https://postimg.cc/8jPjx1Yp)


## Features

- Locating .mp3 files in subdirectories
- Changing speed and volume
- Seeking past and forward
- Skipping
- Adding to queue
- Searching from all songs
## What's next

- Changing size of UI elements using mouse
- Support of other audio formats
- More vivid volume UI
- Changing controls
## Run Locally

Clone the project

```bash
  git clone https://github.com/uvelyr/gomp3
```

Go to the project directory

```bash
  cd gomp3
```

Install dependencies

```bash
  go mod tidy
```

Run the program

```bash
  go run .
```
